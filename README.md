# gdb-scripts

A small repository containing some gdb scripts.
This repository aims to centralize the few GDB scripts I am frequently
using, and has been created to illustrate my talk ("When the kernel writes
its own code: Debugging Runtime-Generated instructions") at OSSEU 2026.

## How to use

- clone the repository in your project
- launch gdb
- in gdb, load the scripts:
`(gdb) source <some_gdb_script>`
- you can now use the commands exported by the loaded script. Refer to each
  script to get documentation about the new commands
